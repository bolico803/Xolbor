# ⚡ Xolbor - Plateforme de Gaming Ultime

Xolbor est une plateforme web moderne et premium dédiée au gaming. Elle intègre un système de marketplace de skins, une gestion d'amis avec chat en temps réel, et une application mobile Android.

## 📱 Télécharger l'Application

Pour une expérience optimale, téléchargez l'application Xolbor directement sur votre téléphone Android :

👉 **[Télécharger l'APK Xolbor (Android)](xolbor_update.zip)** (Si vous avez le fichier `.apk`, mettez le lien direct ici).

## 🚀 Installation & Lancement Rapide (Windows)

Pas besoin de commandes compliquées ! Suivez ces étapes simples pour lancer Xolbor sur votre ordinateur :

1. **Téléchargez** le projet (Bouton "Code" -> "Download ZIP").
2. **Extrayez** le dossier ZIP.
3. **Double-cliquez** sur le fichier :
   ### ⚡ `Lancer_Xolbor.bat`
4. Attendez quelques secondes, puis ouvrez votre navigateur sur : **[http://localhost:5897](http://localhost:5897)**.

## 🔧 Diagnostic Rapide

Si ça ne marche pas, vérifiez :

1. **Le serveur est-il démarré ?** (Fenêtre noire avec "📡 Local: http://localhost:5897")
2. **Le port 5897 est-il libre ?** (Pas d'autre programme qui l'utilise)
3. **Votre navigateur ?** Essayez Chrome, Firefox ou Edge
4. **Les antivirus/firewalls ?** Ils peuvent bloquer le port 5897

### 🚨 Problème connu résolu :
- **Port occupé** → Changé pour le port **5897**
- **Processus zombie** → Nettoyé automatiquement

## 📧 Configuration Email (Optionnel)

Pour recevoir des notifications par email lors des connexions/inscriptions :

1. Ouvrez le fichier `.env`
2. Remplacez :
   ```
   EMAIL_USER=votre_email@gmail.com
   EMAIL_PASS=votre_mot_de_passe_app
   ```
3. Redémarrez le serveur

*Une fois le site ouvert, vous pouvez cliquer sur le bouton **"Installer Xolbor"** dans la barre en haut pour l'avoir sur votre bureau !*
